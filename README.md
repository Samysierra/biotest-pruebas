# BioTest Diagnósticos — sitio de práctica

Sitio estático de demostración para realizar pruebas de software con Selenium IDE. No corresponde a una plataforma clínica real y utiliza datos ficticios.

## Publicación en GitHub Pages

1. Crea un repositorio público en GitHub llamado `biotest-pruebas`.
2. Sube `index.html` y `README.md` a la raíz del repositorio (Code → Add file → Upload files).
3. Abre Settings → Pages.
4. En Build and deployment, elige `Deploy from a branch`, rama `main` y carpeta `/(root)`, luego guarda.
5. Espera a que GitHub Pages publique el sitio. La dirección suele tener la forma `https://TU-USUARIO.github.io/biotest-pruebas/`; reemplaza TU-USUARIO por tu nombre de usuario y confirma el enlace en Settings → Pages.
